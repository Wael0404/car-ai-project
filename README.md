# Car AI Project

Projet d'intelligence artificielle appliquée à l'automobile.

## Structure

```
car-ai-project/
├── src/car_ai/   # Code source principal
├── data/         # Jeux de données (non versionnés)
├── models/       # Modèles entraînés (non versionnés)
├── notebooks/    # Expérimentations Jupyter
└── tests/        # Tests unitaires
```

## Installation

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Lancer les tests

```bash
pytest
```
